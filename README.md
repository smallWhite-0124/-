# 海龟汤命令行游戏（AI 自动生成）
一个基于大模型 API 的命令行海龟汤游戏，自动生成汤面、自动回答是/否/无关紧要，无需人工干预。

## 功能
- AI 自动生成海龟汤汤面
- AI 自动判断玩家问题（是 / 否 / 无关紧要）
- 支持查看答案
- 纯命令行，轻量简洁

## 使用方法
1. 安装依赖
pip install requests

2. 修改代码中的配置
API_KEY = "你的API Key"

3. 运行
python turtle_soup.py

## 技术栈
- Python
- 大模型 API（DeepSeek / 通用 OpenAI 格式接口）
